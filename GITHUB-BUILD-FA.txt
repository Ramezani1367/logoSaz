راهنمای نسخهٔ تمیز GitHub و ساخت Windows
========================================

این بسته سورس تمیز برنامه و workflow ساخت Windows را دارد و عمداً لوگوی نمونه یا فایل شخصی لوگو در آن نیست. Python فقط روی runnerهای GitHub Actions لازم است؛ کاربر Windows برای اجرای EXE به Python نصب‌شده نیاز ندارد.

راه‌اندازی repository
---------------------
1) ZIP سورس را Extract کن و محتوای پوشهٔ `logo_color_studio` را در ریشهٔ repository GitHub قرار بده. فایل‌های مخفی مانند `.gitignore` و پوشهٔ `.github` را هم نگه دار.
2) Commit و push کن؛ یا از Actions → Build Logo Color Studio for Windows → Run workflow ساخت را دستی اجرا کن.
3) پس از موفقیت، artifact به نام `LogoColorStudio-Windows` را از همان اجرای Actions دانلود و Extract کن.
4) پوشهٔ `LogoColorStudio` را کامل نگه دار و `LogoColorStudio\\LogoColorStudio.exe` را اجرا کن. فقط exe را جدا نکن.

مخزن سورس عمداً هیچ فایل لوگوی نمونه یا خصوصی ندارد. برنامه در اجرای نخست و پس از این ارتقا با کتابخانهٔ خالی شروع می‌شود؛ پوشهٔ SVGهای خودت را از Settings انتخاب کن. مهاجرت مسیر قدیمی را یک‌بار فراموش می‌کند، اما فایل‌های اصلی لوگو را از دیسک حذف نمی‌کند. مسیر جدیدی که انتخاب می‌کنی بین اجراها باقی می‌ماند.

ساختار خروجی عمداً onedir است: exe و runtime کنار هم در یک پوشه‌اند، نه چسبیده به یک فایل تک‌تکه. گزینهٔ windowed پنجرهٔ CMD را حذف می‌کند، آیکون به exe اضافه می‌شود و pywebview رابط را در پنجرهٔ مستقل باز می‌کند. اگر build شکست خورد، متن مرحلهٔ قرمز Actions را بررسی کن.

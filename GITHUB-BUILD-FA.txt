راهنمای به‌روزرسانی برنامه در GitHub Actions
============================================

نسخهٔ Desktop Update شامل سورس به‌روز و workflow ساخت Windows است. Python روی سیستم خودت لازم نیست؛ GitHub Actions آن را روی runner خودش استفاده می‌کند.

به‌روزرسانی repository فعلی
---------------------------
1) فایل `LogoColorStudio-Desktop-Update.zip` را Extract کن.
2) فایل‌ها و پوشه‌های داخلش را در ریشهٔ repository فعلی آپلود/جایگزین کن. به‌ویژه `app.py`, `index.html`, `requirements.txt`, `README_FA.txt`, `build-exe.bat`, `start.bat`, پوشهٔ `assets`, و `.github/workflows/build-windows.yml` باید از نسخهٔ جدید باشند.
3) Commit کن. Workflow با push اجرا می‌شود؛ یا در Actions → Build Logo Color Studio for Windows → Run workflow را انتخاب کن.
4) پس از موفقیت، artifact به نام `LogoColorStudio-Windows` را از همان اجرای Actions دانلود و Extract کن.
5) پوشهٔ `LogoColorStudio` را کامل نگه دار و `LogoColorStudio\LogoColorStudio.exe` را اجرا کن. فقط exe را جدا نکن.

مخزن را Private نگه دار؛ پوشهٔ samples دو SVG نمونه دارد. SVGهای خصوصی واقعی را به repository اضافه نکن.

ساختار خروجی عمداً onedir است: exe و runtime در یک پوشه‌اند، نه چسبیده به یک فایل تک‌تکه. گزینهٔ windowed پنجرهٔ CMD را حذف می‌کند، آیکون به exe اضافه می‌شود و pywebview رابط را در پنجرهٔ مستقل باز می‌کند. اگر build شکست خورد، متن مرحلهٔ قرمز Actions را بفرست.

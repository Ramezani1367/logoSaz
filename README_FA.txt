LOGO COLOR STUDIO — راهنمای نسخهٔ Windows
===========================================

این نسخه یک پنجرهٔ مستقل دسکتاپ دارد؛ داخل مرورگر خارجی باز نمی‌شود و فایل خروجی را هم برای دانلود مرورگری نمی‌فرستد. رابط در WebView داخلی Windows اجرا می‌شود. هنگام خروجی، فایل‌ها مستقیم در پوشهٔ انتخابی ذخیره می‌شوند.

نسخهٔ EXE برای کاربر نهایی
--------------------------
اگر EXE را از GitHub Actions گرفته‌ای، ZIP را استخراج کن و کل پوشهٔ `LogoColorStudio` را نگه دار. برنامه را از `LogoColorStudio\LogoColorStudio.exe` اجرا کن. فقط EXE را از پوشهٔ خودش جدا نکن؛ فایل‌های اجرایی و کتابخانه‌ها کنار آن و در `_internal` هستند. این نسخه به Python نصب‌شده روی رایانهٔ تو نیاز ندارد و پنجرهٔ CMD باز نمی‌کند.

اگر WebView2 روی ویندوز نصب نباشد، Runtime رسمی Microsoft Edge WebView2 را نصب کن. ویندوزهای به‌روز معمولاً آن را دارند.

ساخت از سورس (فقط برای توسعه‌دهنده)
-----------------------------------
برای اجرای سورس روی یک سیستم توسعه، Python 3.10+ نصب کن، یک بار `setup.bat` و سپس `start.bat` را اجرا کن. برای ساخت پوشهٔ برنامهٔ قابل‌حمل، `build-exe.bat` را اجرا کن. برای کاربر نهایی، بهتر است artifact ساخته‌شده در GitHub Actions را بگیرد؛ نیازی به Python محلی ندارد.

ظاهر و رفتار برنامه
-------------------
- پنجرهٔ مستقل دسکتاپ با آیکون اختصاصی؛ صفحهٔ مرورگر جداگانه و پنجرهٔ CMD ندارد.
- خروجی‌ها مستقیماً در پوشهٔ خروجی ذخیره می‌شوند و هیچ دانلود خودکاری شروع نمی‌شود.
- ZIP اختیاری است: تیک «ساخت فایل ZIP هم» را فقط وقتی لازم داری فعال کن. ZIP نیز در همان پوشهٔ خروجی ساخته می‌شود؛ تاریخ نام فایل ZIP و صفحهٔ مجموعه با تقویم جلالی است.
- فایل CSV/Excel یا manifest ساخته نمی‌شود.
- تنظیمات داخل صفحهٔ اصلی برنامه باز می‌شود، نه به صورت popup؛ چیدمان تنظیمات دو ستونه و عریض‌تر است.
- پنجره هنگام شروع در مرکز صفحه قرار می‌گیرد؛ خانه و تنظیمات در سمت راست، درست زیر نام و نشان برنامه‌اند.
- رابط فارسی است و کنترل تغییر زبان به انگلیسی ندارد.
- رنگ‌گزین دارای انتخابگر رنگ و فیلد HEX قابل‌ویرایش است؛ حالت تنالیته‌دار تفاوت روشنایی اجزای لوگوی چندرنگ را نگه می‌دارد.
- در تنظیمات، آرت‌بورد خروجی را انتخاب کن: برش دور طرح، آرت‌بورد اصلی SVG، مربع ۱۰۸۰×۱۰۸۰ پیکسل، A4 افقی یا A5 افقی. لوگو با حفظ نسبت ابعاد دقیقاً وسط صفحه قرار می‌گیرد و حاشیهٔ هر ضلع را می‌توانی از صفر تا ۲۵ درصد تنظیم کنی.
- لوگوها ابتدا با رنگ منبع نمایش داده می‌شوند. رنگ‌های شناسایی‌شده و HEX آن‌ها برای کپی‌کردن در کارت نشان داده می‌شوند.
- می‌توان چند نسخهٔ رنگی متفاوت از یک لوگو را به سبد افزود؛ تکراری‌ها دوباره اضافه نمی‌شوند و HEX رنگ در نام فایل خروجی می‌آید.
- هر نسخهٔ داخل سبد یک thumbnail دارد. راست‌کلیک روی کارت امکان بازکردن پوشهٔ فایل در Windows Explorer را می‌دهد.
- نسخه‌های متعدد یک لوگو در گروه جمع‌شونده قرار می‌گیرند؛ نوار پایین سبد تعداد نسخه‌های تیک‌خورده را نشان می‌دهد. در سبد برای حذف یک فرمت روی برچسب آن دوبار کلیک کن؛ از فهرست «＋ فرمت» هم می‌توانی فرمت اضافه کنی.
- دکمهٔ «رنگ‌دهی همهٔ این صفحه» در خانه، حالت تنالیته‌دار یا تک‌رنگ و HEX را به همهٔ کارت‌های در حال نمایش (با رعایت جست‌وجو و فیلترها) اعمال می‌کند؛ نسخه‌های موجود در سبد تغییر نمی‌کنند.
- دکمهٔ «واگردانی» در نوار بالایی، آخرین تغییر گروهی را برمی‌گرداند: رنگ‌دهی صفحه، یکسان‌سازی همه یا پروفایل سبد. با شروع ویرایش دستی سبد/کارت، برای جلوگیری از بازنویسی آن ویرایش‌ها، واگردانی قبلی غیرفعال می‌شود.
- دکمهٔ «یکسان‌سازی همهٔ لوگوها» در صفحهٔ خانه، همهٔ فایل‌های کتابخانه را مستقل از جست‌وجو با حالت رنگ، HEX و فرمت‌های مشترک انتخابی به سبد می‌آورد. نسخه‌های قبلی حذف نمی‌شوند و برای جلوگیری از خروجی چندگانه، تیک نسخه‌های دیگر برداشته می‌شود.
- دکمه‌های صفحهٔ مجموعه کنار هم و زیر عنوان «سبد خروجی» هستند. فهرست کشویی حالت رنگ در پنجره‌های باریک هم رنگ نوشتهٔ پرکنتراست و اندازهٔ خوانا دارد.
- «صفحهٔ همهٔ لوگوها» همهٔ SVGهای کتابخانه را مستقل از جست‌وجو و سبد در یک صفحهٔ A4/A5 افقی یا مربع ۱۰۸۰×۱۰۸۰ می‌چیند. «صفحهٔ انتخاب‌های سبد» فقط نسخه‌های تیک‌خوردهٔ سبد را در یک صفحه می‌سازد؛ نسخه‌های رنگی تکراری با برچسب رنگ از هم مشخص می‌شوند. هر دو خروجی، رنگ اصلی یا رنگ دلخواه، نمایش نام برند و PDF/SVG/PNG/AI را پشتیبانی می‌کنند.
- در Settings، پروفایل‌های آماده فقط روی نسخه‌های تیک‌خورده اعمال می‌شوند: «شبکه‌های اجتماعی» مربع ۱۰۸۰ با PNG و حاشیهٔ ۸٪، «چاپ A4» با PDF و حاشیهٔ ۵٪، و «فهرست یک‌صفحه‌ای انتخاب‌ها» که یک PDF تک‌صفحه‌ای A4 از همان انتخاب‌های سبد می‌سازد. از همین بخش می‌توان پریست شخصی با نام، آرت‌بورد، حاشیه، حالت رنگ/HEX و فرمت‌ها ثبت، انتخاب و حذف کرد؛ پریست‌های ذخیره‌شده بین اجراها می‌مانند.
- تنظیمات جاری رنگ و خروجی (مانند حالت رنگ کارت‌ها، آرت‌بورد/حاشیه و تیک فرمت‌ها) در هر شروع برنامه به پیش‌فرض برمی‌گردند؛ پریست‌های ذخیره‌شده و مسیرهای کتابخانه/خروجی حفظ می‌شوند.
- چیدمان صفحهٔ مجموعه بر اساس نام برند، زبان یا ترتیب دلخواه انجام می‌شود. در حالت ترتیب دلخواه، لوگوها را با drag-and-drop یا دکمه‌های ↑ و ↓ جابه‌جا کن؛ ترتیب ذخیره می‌شود. تعداد ستون‌ها نیز قابل تنظیم یا خودکار است. حاشیهٔ صفحهٔ مجموعه جدا از حاشیهٔ خروجی تک‌لوگوها تنظیم می‌شود.
- فونت‌ها و کنترل‌ها بزرگ‌تر شده‌اند و کارت لوگو هنگام hover حرکت یا انیمیشن ندارد.

کتابخانه و خروجی
----------------
پوشهٔ نمونه شامل Logo_Zama.svg و Logo_Miele.svg است. از Settings کتابخانهٔ SVG واقعی را انتخاب کن؛ پوشه‌های زیرمجموعه نیز جست‌وجو می‌شوند. فایل‌های لوگوی واقعی روی سیستم محلی انتخاب می‌شوند؛ برای build لازم نیست آن‌ها را در GitHub قرار بدهی.

خروجی‌ها در پوشهٔ انتخابی و زیرپوشهٔ نام برند ذخیره می‌شوند. تاریخ موجود در نام فایل‌های صفحهٔ مجموعه و ZIP با تقویم جلالی است. PNG و WebP شفاف‌اند مگر اینکه تنظیم پس‌زمینه را خاموش کنی؛ در آن حالت رنگ پس‌زمینه قابل تنظیم است. عرض پیش‌فرض raster برابر 2048 پیکسل است؛ در آرت‌بورد مربع، PNG و WebP دقیقاً ۱۰۸۰×۱۰۸۰ پیکسل خواهند بود. برای A4/A5، وضوح raster جداگانه تنظیم می‌شود. دکمهٔ «بازکردن» پوشهٔ خروجی را در Explorer باز می‌کند.

در Settings، برای ذخیرهٔ مسیر جدید «اعمال» را بزن. اگر مسیر کتابخانه یا خروجی را پاک کنی و اعمال بزنی، به مسیر پیش‌فرض برمی‌گردد: کتابخانهٔ نمونه یا پوشهٔ خروجی دسکتاپ؛ این مسیرها خالی باقی نمی‌مانند.

حالت رنگ
---------
- رنگ اصلی (پیش‌فرض): همان رنگ‌های منبع SVG نمایش داده می‌شوند.
- تنالیته‌دار: روشنایی رنگ‌های SVG به طیفی از رنگ مقصد تا روشن حفظ می‌شود.
- تک‌رنگ: رنگ‌های قابل‌شناسایی شکل‌ها یکسان می‌شوند.

فرمت‌ها و Illustrator
---------------------
فرمت‌های فعال: SVG، PNG، WebP، PDF و AI. SVG، PNG و WebP در خود برنامه ساخته می‌شوند. PDF و AI به Windows، Adobe Illustrator نصب‌شده و pywin32 نیاز دارند؛ برنامه SVG رنگ‌آمیزی‌شده را در Illustrator باز و ذخیره می‌کند. این دو فرمت باید در Illustrator واقعی آزمایش شوند.

برای بهترین سازگاری، متن لوگو را در Illustrator به outline تبدیل و تصاویر را Embed کن. SVGهایی که به فایل تصویر بیرونی وابسته‌اند تا حد امکان مستقل می‌شوند. لایهٔ `__ProGuides__` در SVG خروجی مخفی می‌ماند.

حریم خصوصی
-----------
سرور کمکی فقط به 127.0.0.1 وصل می‌شود و فقط داخل پنجرهٔ دسکتاپ استفاده می‌شود. فایل‌های لوگو به GitHub یا اینترنت ارسال نمی‌شوند؛ اما فایل‌هایی که برای build داخل repository قرار می‌دهی، GitHub آن‌ها را می‌بیند. برای repository نمونه‌های فعلی را Private نگه دار و SVGهای محرمانهٔ اصلی را به repo اضافه نکن.

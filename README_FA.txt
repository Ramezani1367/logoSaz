LOGO COLOR STUDIO — راهنمای نصب و اجرا
========================================

این برنامه برای Windows ساخته شده است. رابط HTML داخل مرورگر باز می‌شود و یک سرور محلی Python فقط روی همین رایانه اجرا می‌شود؛ هیچ‌یک از فایل‌های لوگو به اینترنت ارسال نمی‌شوند.

شروع سریع
----------
1) Python 3.10 یا جدیدتر را نصب کن و هنگام نصب، گزینهٔ Add Python to PATH را فعال کن.
2) پوشهٔ برنامه را از ZIP بیرون بیاور.
3) یک‌بار روی setup.bat دوبار کلیک کن تا وابستگی‌های Python نصب شوند (این مرحله به اینترنت نیاز دارد). برای خروجی AI/EPS نیز Illustrator باید نصب باشد.
4) سپس روی start.bat دوبار کلیک کن.
5) اگر مرورگر خودکار باز نشد، نشانی‌ای را که در پنجرهٔ سیاه نمایش داده می‌شود (معمولاً http://127.0.0.1:8765) در مرورگر باز کن.
6) برای بستن برنامه، پنجرهٔ سیاه را فعال کن و Ctrl+C بزن.

نصب وابستگی‌ها
--------------
بار اول، در پوشهٔ برنامه روی نوار آدرس File Explorer کلیک کن، cmd بنویس و Enter بزن. سپس اجرا کن:

  py -3 -m pip install -r requirements.txt

رندر PNG/WebP/JPG و برش خودکار با resvg-py انجام می‌شود و به Cairo/GTK جداگانه نیاز ندارد. اگر setup.bat خطا داد، Python و اتصال اینترنت را بررسی کن. خطای مربوط به pywin32 را با نصب مجدد وابستگی‌ها رفع کن.

کتابخانه و خروجی
----------------
- پوشهٔ پیش‌فرض کتابخانه، پوشهٔ samples کنار برنامه است و دو فایل نمونهٔ زاما و Miele دارد.
- برای استفادهٔ روزانه، از دکمهٔ «انتخاب پوشه» یا Settings، پوشه‌ای که SVGها در آن هستند انتخاب کن. زیرپوشه‌ها هم جست‌وجو می‌شوند.
- خروجی‌ها به‌صورت پیش‌فرض در Desktop\Logo Exports ذخیره می‌شوند؛ مسیر قابل تغییر است.
- از فهرست «قاب خروجی» در سبد می‌توانی برای هر نوبت حفظ صفحهٔ اصلی SVG یا برش خودکار دور لوگو با اندکی حاشیه را انتخاب کنی؛ برش برای SVG/PDF و raster انجام می‌شود و انتخاب پیش‌فرض «برش دور لوگو» است.
- فایل‌های خروجی بر اساس نام برند داخل زیرپوشه ذخیره می‌شوند. یک ZIP و گزارش CSV هم ساخته می‌شود؛ ZIP پس از اتمام به‌صورت دانلود مرورگر ارائه می‌شود.
- تنظیمات و علاقه‌مندی‌ها در %LOCALAPPDATA%\LogoColorStudio نگه‌داری می‌شوند.

حالت‌های رنگ
------------
- تنالیته‌دار (پیش‌فرض): روشنایی نسبی رنگ‌های SVG مبناست؛ رنگ مقصد به‌صورت تون‌های تیره تا روشن اعمال می‌شود و سفید منبع سفید می‌ماند.
- تک‌رنگ: رنگ‌های قابل‌شناسایی همهٔ شکل‌ها به همان رنگ مقصد تبدیل می‌شوند.
- رنگ اصلی: رنگ‌های SVG دست‌نخورده باقی می‌مانند.

قالب‌ها
-------
SVG خروجی برداری است. در Windows، PDF نیز از طریق Illustrator به‌صورت برداری ذخیره می‌شود. PNG و WebP می‌توانند پس‌زمینهٔ شفاف داشته باشند؛ JPG همیشه با رنگ پس‌زمینه‌ای که انتخاب می‌کنی ترکیب می‌شود. عرض raster پیش‌فرض 2048 پیکسل است.

برای AI و EPS، Windows، Adobe Illustrator و pywin32 لازم است؛ برنامه فایل SVG رنگ‌آمیزی‌شده را با Illustrator باز و ذخیره می‌کند. اگر Illustrator پنجرهٔ تأیید نشان داد، آن را تأیید کن.

برای بهترین سازگاری، در Illustrator متن لوگو را به outline تبدیل و SVG را با تصاویر Embed ذخیره کن. SVGهایی که به فایل‌های تصویر بیرونی وابسته باشند تا حد امکان هنگام خروجی مستقل می‌شوند. فیلترهای خاص Illustrator یا ویژگی‌های SVG ناسازگار با renderer ممکن است نیاز به بررسی در Illustrator داشته باشند.

بسته‌بندی exe (اختیاری)
-----------------------
پس از نصب نیازمندی‌ها، روی build-exe.bat دوبار کلیک کن. فایل ساخته‌شده در dist\LogoColorStudio.exe قرار می‌گیرد. اگر رندر resvg-py یا Illustrator COM در سیستم مقصد فراهم نباشد، آن قابلیت‌ها در exe هم در دسترس نخواهند بود. اجرای start.bat برای نصب و رفع خطا ساده‌تر است.

حریم خصوصی
-----------
سرور به 127.0.0.1 متصل است، نه شبکهٔ عمومی. پوشهٔ تنظیمات حاوی مسیرهای محلی و علاقه‌مندی‌ها است. برای ذخیرهٔ تنظیمات در فایل، دکمهٔ پشتیبان را در Settings بزن.

نسخهٔ نمونه برای آزمون اولیه آماده است؛ خروجی PDF/AI/EPS از طریق Illustrator باید روی رایانهٔ Windows کاربر با Illustrator نصب‌شده آزمایش شود.
